# 0003. Отдельный репозиторий парсеров, формат пакета v3

Статус: принято (2026-10-22)

## Контекст

Пакеты парсеров MVP лежат в отдельном репозитории, подключённом сабмодулем, и
используют предыдущую схему конфигурации. MVP продолжает работать в продакшене
и обновляет этот сабмодуль.

## Решение

- Для `dailyscraper` создаётся **новый** репозиторий парсеров и подключается
  сабмодулем в `scrapers/`. Репозиторий парсеров MVP остаётся за MVP.
- Пакет парсера v3:

  ```
  scrapers/<name>/
    scraper.json    # schema_version: 3, options + pages (+ navigation, discovery, health_check, inputs)
    pipeline.py     # только при нестандартном сценарии
    actions.py      # только при site-specific hooks
  ```

- Пакеты переносятся по одному, уже сконвертированными, и только используемые.
  Конвертер предыдущей схемы — одноразовая утилита в `tools/`, а не адаптер в
  коде фреймворка.

## Последствия

- Пока MVP в продакшене, исправления селекторов приходится делать в двух местах.
  Это временно, до отключения MVP.
- До этапа 7 фреймворк тестируется на контролируемых пакетах из `tests/`.
- Сабмодуль `scrapers/` подключается не раньше этапа 1–2.
