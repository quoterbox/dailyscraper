# 0006. `roadmaps/` как память проекта

Статус: принято (2026-10-22)

## Решение

- Планы, решения, статус и замечания хранятся в `roadmaps/` обычными
  Markdown-файлами. Отдельный файл инструкций для ассистента (`CLAUDE.md`) не
  ведётся.
- Новая сессия работы начинается с чтения [README.md](../README.md) и
  [status.md](../status.md).
- `status.md` обновляется в конце каждого шага; решения — только через новые ADR.

## Последствия

- Контекст проекта не зависит от конкретной сессии ассистента и читается людьми
  так же, как ассистентом.
- Ассистент не получает контекст автоматически: в новой сессии нужно попросить
  прочитать `roadmaps/`.
