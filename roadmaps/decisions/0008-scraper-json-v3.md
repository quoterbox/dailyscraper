# 0008. Формат `scraper.json` v3

Статус: принято (2026-10-22)

## Контекст

У предыдущего формата пакета парсера плоские секции `xpath_options`,
`time_options`, `scroll_options`, ключи в верхнем регистре (`CSS`, `XPATH`,
`MAIN_XPATH`, `RELATIVE_XPATH`, `FALLBACK_SELECTORS`) и неявные правила: при
наличии и CSS, и XPath используется XPath; общий XPath элементов ищется
посимвольно (ломается на `li[9]`/`li[10]` и `li[12]`/`li[13]`). Прототип ввёл
типизированные страницы с templates, но остался на старых ключах селекторов.

## Решение

- Корень: `schema_version: 3`, `name` (= имя каталога пакета), `website`,
  `links` (группы `list` с `urls` или `template` с `url_template`), `navigation`,
  `page_state` (общие правила), `discovery`, `health_check`, `inputs`, `pages`
  (`auth`, `list`, `detail`), `options` (свободные настройки для hooks пакета).
  Неизвестные ключи — ошибка.
- Каждая страница описывает свои `templates`, `waits` (секунды), `delays`
  (диапазоны `[min, max]`), `scroll` и `state` (правила page state поверх общих).
- **Селектор** — упорядоченные альтернативы:
  `{"css": ...}` или `{"xpath": ...}` (строка или список) либо
  `{"selectors": [{"xpath": ...}, {"css": ...}]}`, когда важен порядок между
  видами. Плюс `attribute`, `wait`, `prepare` (`regex`, `mode`:
  `find|remove|replace`, `replace_with`), `parent_text`. Одновременные `css` и
  `xpath` без `selectors` — ошибка: порядок должен быть явным.
- **Элементы списка**: `item` задаёт селектор всех элементов явно; иначе он
  выводится из абсолютных XPath первого и второго образца (`first_item`,
  `second_item`), которые должны различаться ровно одним шагом и только его
  индексом; иначе берётся CSS `first_item.body`. Абсолютные XPath полей
  переводятся в относительные к элементу. Относительный XPath — тот, что
  начинается с `.`.
- Таблицы свойств detail (`property_groups`): строки — как элементы списка,
  ячейки `name`/`value`, `properties` — имя выходного поля → подпись строки.
  Выходное поле — `property_<group>_<name>`.
- Проверка полноты detail: `required_fields` шаблона и `required` группы.
- Секреты — только ссылками `${env:NAME}`.
- Переход со старого формата — одноразовой утилитой
  `tools/convert_scraper.py`: то, что не переносится, она перечисляет в
  предупреждениях, а результат сразу проверяет загрузкой.

## Последствия

- Конфиг неизменяем: вычисленные селекторы хранятся в `Compiled*Template`, а не
  дописываются в модели.
- Шаблоны компилируются при загрузке пакета: ошибка селектора видна до запуска
  браузера, с указанием шаблона.
- Значения по умолчанию ожиданий (секунды): list — `item_body` 10, `item` 10,
  `field` 1, `next_page` 1, `last_page` 2; detail — `page` 30, `field` 1,
  `property` 1; auth — `login_form` 120.
- Настройки выполнения (кэш discovery, повторы через другие прокси,
  отладка браузера) в `scraper.json` не входят: это runtime-конфигурация.
