# 0001. Новый репозиторий и чистые имена

Статус: принято (2026-10-22)

## Контекст

У проекта два предшественника:

- **MVP** — рабочий синхронный фреймворк на Playwright с проверенной на долгих
  прогонах инфраструктурой: прокси, preflight, page state, SQLite control
  plane, recovery, export. Архитектура перегружена: взаимозависимые пакеты,
  ранняя привязка прокси к задачам, несколько моделей запуска браузера,
  facade-модули ради monkeypatch в тестах.
- **Прототип** — простая модель страниц (`ListPage`/`DetailPage`/`AuthPage`,
  templates, page-scraper на тип страницы, pipeline, hooks), но на Selenium и
  без инфраструктуры.

Имена у предшественников накопили историю и разное написание.

## Решение

- Новый репозиторий `dailyscraper`. Предшественники не меняются и служат
  источниками: MVP работает в продакшене до паритета, прототип — архив.
- Код переносится копированием по компонентам ([plan.md](../plan.md),
  раздел 11), модуль за модулем и с тестами. История файлов не переносится.
- Имена сразу чистые, без совместимых алиасов:
  - пакет `dailyscraper`;
  - `scraper` с одной «p» везде: `scrapers/`, `scraper.json`, `ScraperActions`;
  - hooks без префикса `actions_`;
  - переменные окружения `DAILYSCRAPER_*`.

## Последствия

- Пакеты парсеров предыдущего формата не загружаются как есть: их нужно
  сконвертировать (см. [0003](0003-separate-scrapers-repository.md)).
- Ни шима старого пакета, ни постоянного адаптера старой схемы в коде нет.
