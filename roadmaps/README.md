# Roadmaps

Рабочая память проекта: что строим, что решили, что сделано и что осталось.
Новую сессию работы над проектом начинайте с чтения этой папки, в первую очередь
[status.md](status.md).

| Файл | Содержание | Когда обновлять |
|---|---|---|
| [status.md](status.md) | Текущий этап, что сделано, что в работе, следующий шаг | В конце каждого шага работы |
| [plan.md](plan.md) | Целевая архитектура, контракты компонентов, карта переноса, этапы | Когда меняется архитектура или порядок этапов |
| [decisions/](decisions/) | ADR: одно решение — один файл | Когда принимается или отменяется решение |
| [notes.md](notes.md) | Замечания по окружению и тестовому сайту | По мере появления |
| `local/` | Локальные рабочие записи, в `.gitignore` | — |

В репозитории — только основное: архитектура, решения, статус. Пути,
внутренние вопросы и подробности переноса хранятся в `local/` и в git не
попадают.

## Правила работы

- Репозиторий публичный: любые изменения корневого `README.md` и других
  публичных описаний проекта сначала согласуются с владельцем.
- Git ведёт владелец ([0004](decisions/0004-branches-and-git-ownership.md)).
- Комментарии в коде — только там, где без них неочевидно *почему* код такой:
  обходные решения, внешние ограничения, неочевидные контракты. Комментарии,
  пересказывающие имена и код, не пишутся. Docstring пакета-слоя описывает его
  ответственность.
- ruff обрабатывает только `*.py` и `*.pyi` (`[tool.ruff] include` в
  `pyproject.toml`). JSON-конфиги, пакеты парсеров и Markdown он не трогает;
  это ограничение не снимается.
